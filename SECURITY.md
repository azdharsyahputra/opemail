# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x (RC/GA) | :white_check_mark: |
| < 0.9.0 | :x:                |

## Reporting a Vulnerability

We take the security and privacy of MailOpen seriously. If you believe you have found a security vulnerability in MailOpen:

1. **Do NOT open a public GitHub issue**.
2. Email your findings directly to the security team at `security@mailopen.dev` or the maintainer at `csadeveloper@gmail.com`.
3. Include detailed steps to reproduce the vulnerability, sample payloads (without sensitive personal data), and the software version.

### Response Timelines
- **Initial Acknowledgment**: Within 24 hours
- **Triage & Reproduction**: Within 72 hours
- **Fix & Patch Release**: Critical vulnerabilities patched within 7 days
